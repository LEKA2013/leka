# Máscaras de domínio

Coloque aqui a geometria oficial (ou a já usada no CENSIPAM) da **Amazônia Legal**.

- Formatos aceitos previstos: shapefile (`.shp` + sidecars) ou GeoJSON.
- **Não** há geometria inventada neste repositório.
- Indique o arquivo via variável `CENSIPAM_AMAZONIA_LEGAL_MASK` ou em `configs/paths.yaml`.

Arquivos de máscara **não** devem ser commitados se forem grandes ou de uso interno — mantenha-os localmente e documente a fonte no inventário.
